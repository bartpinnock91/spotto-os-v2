# Spotto

**Type:** B2C Platform
**Website:** [spotto.be](https://www.spotto.be)

## Overview

Belgian real estate platform for property search - buying and renting.

## Key Features

- Property listings (residential & commercial)
- Advanced search with filters
- Travel-time based search
- Real estate professional directory
- Spotto Assistance (insurance product)
- Market insights blog

## Target Users

- Homebuyers
- Renters
- Property owners
- Real estate professionals
