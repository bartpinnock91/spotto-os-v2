## Queries gebruikt

```sql
-- Gemeenten
SELECT COUNT(*) FROM Customers WHERE CustomerType = 4 AND Status NOT IN (3, 4)

-- Detail gemeenten
SELECT c.Name, c.Status, c.Address_Municipality,
       (SELECT COUNT(*) FROM Publications p WHERE p.CustomerId = c.Id AND p.IsOnline = 1) AS ActievePublicaties
FROM Customers c WHERE c.CustomerType = 4 AND c.Status NOT IN (3, 4) ORDER BY c.Name

-- Aanbieders
SELECT COUNT(DISTINCT c.Id) FROM Customers c WHERE c.CustomerType IN (2, 3) AND c.Status NOT IN (3, 4)

-- Actieve publicaties
SELECT COUNT(*) FROM Publications WHERE IsOnline = 1

-- Bedrijfsvastgoed
SELECT COUNT(*) FROM Publications WHERE IsOnline = 1 AND PropertyType IN (4, 7, 9, 10, 11, 12, 13, 14)

-- Uitsplitsing pandtype
SELECT PropertyType, COUNT(*) FROM Publications WHERE IsOnline = 1 AND PropertyType IN (4,7,9,10,11,12,13,14) GROUP BY PropertyType

-- Transactietypes
SELECT TransactionType, COUNT(*) FROM Publications WHERE IsOnline = 1 GROUP BY TransactionType

-- Contactaanvragen
SELECT FORMAT(Created_On, 'yyyy-MM'), COUNT(*) FROM Questions WHERE Created_On >= DATEADD(MONTH, -12, GETDATE()) GROUP BY FORMAT(Created_On, 'yyyy-MM')

-- Gebruikers & favorieten
SELECT COUNT(*) FROM Users
SELECT COUNT(*) FROM FavoritePublications WHERE Created_On >= DATEADD(MONTH, -12, GETDATE())
```

**Nota:** PublicationHits en PublicationSearches zijn te groot om direct te queryen. Voor trafiekdata kan Google Analytics (GA4 property 491908260) geconsulteerd worden.

## Queries gebruikt (vervolg)

```sql
-- Contactaanvragen bedrijfsvastgoed
SELECT FORMAT(q.Created_On, 'yyyy-MM'), COUNT(*)
FROM Questions q JOIN Publications p ON q.PublicationId = p.Id
WHERE q.Created_On >= DATEADD(MONTH, -12, GETDATE()) AND p.PropertyType IN (4,7,9,10,11,12,13,14)
GROUP BY FORMAT(q.Created_On, 'yyyy-MM')

-- Aanbieders met actief bedrijfsvastgoed
SELECT COUNT(DISTINCT p.CustomerId) FROM Publications p WHERE p.IsOnline = 1 AND p.PropertyType IN (4,7,9,10,11,12,13,14)

-- Bedrijfsvastgoed per transactietype
SELECT TransactionType, COUNT(*) FROM Publications WHERE IsOnline = 1 AND PropertyType IN (4,7,9,10,11,12,13,14) GROUP BY TransactionType

-- Top gemeenten bedrijfsvastgoed
SELECT TOP 30 Address_Municipality, COUNT(*) FROM Publications WHERE IsOnline = 1 AND PropertyType IN (4,7,9,10,11,12,13,14) AND Address_Municipality IS NOT NULL GROUP BY Address_Municipality ORDER BY COUNT(*) DESC

-- Onbekende transactietypes
SELECT TransactionType, PropertyType, COUNT(*) FROM Publications WHERE IsOnline = 1 AND TransactionType IN (7,8) GROUP BY TransactionType, PropertyType

-- Prijsranges koop bedrijfsvastgoed
SELECT CASE WHEN Price_Value < 100000 THEN '< 100K' ... END, COUNT(*) FROM Publications WHERE IsOnline = 1 AND PropertyType IN (4,7,9,10,11,12,13,14) AND TransactionType = 1 GROUP BY ...

-- Aanbieders per databron
SELECT ci.DataSource, COUNT(DISTINCT c.Id) FROM Customers c JOIN CrmIntegrations ci ON ci.CustomerId = c.Id WHERE c.Status NOT IN (3,4) GROUP BY ci.DataSource
```
