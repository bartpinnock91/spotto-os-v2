# Spotto

**Type:** B2C Platform
**Website:** [spotto.be](https://www.spotto.be)

## Overview

Belgian real estate platform for property search - buying and renting.

## Key Features

- Property listings (residential & commercial)
- Advanced search with filters
- Travel-time based search
- Real estate professional directory
- Spotto Assistance (insurance product)
- Market insights blog

## Target Users

- Homebuyers
- Renters
- Property owners
- Real estate professionals

## Tracking & Attribution

All marketing channels use UTM parameters for attribution:

| Parameter      | Purpose                          |
| -------------- | -------------------------------- |
| `utm_source`   | Traffic source (google, meta, chatgpt, etc.) |
| `utm_medium`   | Medium type (cpc, organic, ai-assistant, etc.) |
| `utm_campaign` | Campaign name                    |
| `utm_term`     | Keyword (for paid search)        |
| `utm_content`  | Ad/content variant               |

**Platform-specific click IDs:**
- Google Ads: `gclid`, `gbraid`, `wbraid`
- Meta Ads: `fbclid`
- Microsoft Ads: `msclkid`
- Pinterest Ads: `epik`
